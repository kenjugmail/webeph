One library · Local authority

Bring what you already own.

01

Add without surrendering

Reference a local game where it already lives. Hearthrail does not move, upload, patch, or claim ownership of its files.

02

Keep the launch path local

Local games remain available while signed out. An account can add synchronization; it is not the authority for files on your machine.

03

Separate untrusted bundles

Imported web games run in their own window with no Hearthrail capability and no network access. Compatibility does not widen that boundary.

04

Recover deliberately

Declare save locations, capture versioned snapshots, and restore behind confirmation. Release verification and rollback stay visible instead of happening silently.

Ownership boundary

“Yours offline” is a product rule, not a campaign line.

Hearthrail does not require a runtime lease to open a local game. Signing out does not erase installed releases or local organization.

Local paths, save files, play history, and provider credentials are not uploaded by default. When a read fails, the interface reports that failure rather than pretending the library is empty.
