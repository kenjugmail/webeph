Data and account boundaries

Clear about what crosses the network.

Hosted routes send the prompt and code context needed for a completion through Orrery Cloud to the configured provider. Ephemerent meters usage, does not retain relay content beyond fulfilling the request, and does not use your code or prompts to train its own models.

01

Explicit hosted route

Nexus labels the selected DeepSeek API, Doubleword, or Arbiter route before a run starts.

02

Purpose-limited relay

Only the prompt and context needed for the completion are relayed to the configured provider.

03

Content is not metering

Stored usage counters are token totals and timestamps, not copies of prompt content.

04

Your review remains final

Keep source-control backups and inspect changes before accepting, running, or shipping output.

Questions

Before you download.

What leaves my machine?
When you run a hosted route, the prompt and code context needed for that completion pass through Orrery Cloud to the configured provider. Usage counters store totals and timestamps; Ephemerent does not retain relay content beyond fulfilling the request or use it to train its own models. See the privacy policy for the full boundary.
Which platforms are supported?
The current beta packet targets Windows. macOS and Linux are on the roadmap; availability and update delivery may change during beta.
Can I use Orrery without subscribing?
You can inspect preview setup, open Nexus, prepare a workspace, and configure routes. Real agent runs require a trial, subscription, or invite grant. Legacy local access remains honored for existing buyers but is no longer sold.
Which hosted routes are included?
Pro, Max, and Ultra include monthly DeepSeek API, Doubleword, and Arbiter credits at the amounts shown above. Routes and capacity remain subject to beta and provider availability.
How is the winning attempt chosen?
By execution, not impression. Each attempt is run against your tests, type-checks, and lint; an automatic reviewer scores them and keeps the winner before merging it back.
Can I cancel anytime?
Yes. Paid tiers are monthly via Stripe and cancel anytime — access runs to the end of the paid period. Token quotas reset each billing month and don't roll over.
