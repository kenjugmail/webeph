# Stochastic Witness Calculus v4.1 revision chapter

Version 4.1 preserves the exact proof-status, universal-lifting, mass-gap, and analytic-tail results introduced in version 4. It adds a well-founded induction rule for infinite instance families.

## Theorem V4.5 — well-founded inductive witness lifting

Let `(I, ≺)` be a well-founded instance order and let `B` be a set of base instances carrying exact SWC certificates. For every nonbase instance `i`, suppose an exact reduction chooses finitely many dependencies `j ≺ i` and provides a checked transformer that converts valid witnesses for those dependencies into a valid witness for `i`.

If every base instance has a valid witness and every nonbase instance has such a verified witness-lifting reduction, then every instance in `I` has a valid witness.

Proof: Apply well-founded induction. Assume every `j ≺ i` has a valid witness. If `i` is a base instance, its exact certificate supplies one. Otherwise the dependencies have witnesses by the induction hypothesis and the checked lifting map constructs a witness for `i`.

## Corollary V4.6 — divisor-to-multiple lifting for Erdős–Straus

If `d | n` and

`4/d = 1/x + 1/y + 1/z`,

then with `n = kd`,

`4/n = 1/(kx) + 1/(ky) + 1/(kz)`.

Therefore composite instances lift from certified factors. This reduces the unresolved induction domain to the remaining prime class.

## Application boundary

Ordinary induction on a prime `p` does not close the conjecture unless one proves a strict descent from every remaining prime to lower-rank certified instances together with a witness-lifting map. A complete proof may instead use another well-founded rank, an exact family cover, a mass-gap theorem, or an analytic tail theorem.

Version 4.1 formalizes the induction rule and the valid multiplicative lift. It does not assume the missing descent for primes congruent to 1 modulo 24.
